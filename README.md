# QR Code Generator

A simple and responsive QR Code Generator built using HTML, CSS, and JavaScript. The application allows users to generate QR codes for text or URLs and download them as an image.

## Features

- Generate QR codes from text or URLs
- Download generated QR codes
- Simple and responsive user interface
- Popup preview for generated QR codes
- Input validation for empty fields

## Technologies Used

- HTML5
- CSS3
- JavaScript
- QR Code Generator API

## Project Structure

- `index.html` – Main webpage
- `style.css` – Styling and layout
- `app.js` – QR code generation and download logic

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using the Live Server extension or any web browser.
4. Enter text or a URL.
5. Click **Generate QR Code**.
6. Download the generated QR code if required.

## API Used

- QR Code Generator API (`https://api.qrserver.com/v1/create-qr-code/`)
